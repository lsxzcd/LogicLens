========================================================================
 LogicLens 快速验证包
 解压后请按本文档从上到下执行
========================================================================

本包包含完整的智能体代码，只需要 Python 3.11+，不需要安装任何第三方库。

------------------------------------------------------------------------
 第 0 步：确认 Python 可用
------------------------------------------------------------------------

在本文件夹里按住 Shift + 右键 → 选择「在此处打开 PowerShell 窗口」
（或先打开 PowerShell，再用 cd 切到本文件夹）

然后输入：

    python --version

预期：显示 Python 3.11 以上，例如 "Python 3.14.8"

如果提示「不是内部或外部命令」，试试：

    py -3 --version


------------------------------------------------------------------------
 第 1 步：零依赖自检（约 10 秒）
------------------------------------------------------------------------

    python -m unittest discover -s tests

预期输出：

    Ran 124 tests in 9.0s

    OK

★★★ 这一条是本包最重要的验证 ★★★
它证明：我们的代码在此机器上「零安装依赖」即可运行。


------------------------------------------------------------------------
 第 2 步：架构与解析检查（约 5 秒）
------------------------------------------------------------------------

    python tools\check_architecture.py

预期：

    architecture guard: no hardcoded testbench path in agent/


    python tools\check_parsing.py

预期：

    ===== 7 task(s), 6 fully correct, 0 known upstream issue(s), 1 unnamed, 0 unexplained =====

（注意：本包只带 7 道题目用于验证。完整 156 道题可用
  python tools\fetch_verilogeval_problem.py --all experiments\data\verilogeval 重建，
  但那需要能访问 GitHub，本机目前不行。）


------------------------------------------------------------------------
 第 3 步：三级判定（需要 Vivado，约 3 分钟）
------------------------------------------------------------------------

本机的 Vivado 在：E:\2025.2\Vivado

先指给它：

    $env:LOGICLENS_VIVADO = "E:\2025.2\Vivado\bin\vivado.bat"

确认路径存在：

    Test-Path $env:LOGICLENS_VIVADO
    （预期输出 True）

然后跑真实的三级判定（编译 → 仿真 → 综合）：

    python experiments\p05_verify.py

预期输出：

    ===== 3 cases, 0 failed assertion(s), 0 env-blocked =====

★ 这一条证明：编译/仿真/综合三级判定在此机器上真的能跑通。
  它会在 experiments\runs\ 下留下完整日志和报告，可事后核验。


------------------------------------------------------------------------
 如果第 3 步报错
------------------------------------------------------------------------

报 "Vivado not found"：
    → 说明 LOGICLENS_VIVADO 没设对，重新执行上面的 $env: 命令
      注意：$env: 只在当前窗口有效，关掉窗口就要重设

报 env-blocked（>0）：
    → 记录 experiments\runs\ 下对应目录里 flow_result.json 的
      "synthesis_error" 字段内容，把这个发回来

其它报错：
    → 把完整报错文字发回来，先不要自己想办法绕


========================================================================
 需要向老师确认的问题（重要）
========================================================================

1. 这台机器上允许安装软件吗？
   我们的智能体需要一个本地模型推理服务（Ollama，约 1.5 GB 安装包 + 模型）。
   如果允许，会装在 E 盘，测完可卸载。
   如果不允许，我们只做上面第 1~3 步的验证。

2. 最终评测是在这台机器上，还是在赛事方的容器环境里？

3. 这台机器上的显卡（AMD Radeon AI PRO R9700）是物理直通，
   还是通过 Hyper-V 半虚拟化（GPU-PV）给过来的？
   （Windows 报告的厂商 ID 是 1414 = Microsoft，不是 AMD 的 1002，
     这会影响 ROCm 能否使用。）


========================================================================
 背景：这个包是干什么的
========================================================================

项目名：LogicLens
参赛：全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道选题
      AMD 赛道 · RTL/HLS 本地智能体设计赛道（RTL Track）

它做什么：
    读自然语言题目 → 本地模型生成 Verilog → 用真实 Vivado 做三级判定
    （可编译 → 仿真通过 → 可综合）→ 失败就定位原因并局部修复

设计原则：只用 Python 标准库，不引入第三方依赖。
这就是为什么本包能在任何有 Python 3.11+ 的机器上直接运行。


========================================================================
 这个包里有什么（108 个文件，0.22 MB）
========================================================================

agent\          智能体核心（规格解析、错误分类、修复策略、结构检查）
skill\          技能包：从真实失败中提炼的可复用规则
vivado\         三级判定的 Tcl 流程脚本
tools\          自检与辅助工具
tests\          124 个单元测试
experiments\    验证脚本 + 7 道 VerilogEval 题目（含官方测试台）
serve\          推理服务的配置与启动脚本
model\          MODEL.md（模型声明，部分字段待实测）
docs\           全部文档，其中：
                  status-log-zh.md          项目全貌、已完成/未完成
                  what-we-verify-zh.md      我们到底要验证什么（建议先看）
                  task-allocation-zh.md     队友分工
REPORT.md       设计报告
Dockerfile      提交物容器定义（官方基础镜像名待公布）

不需要的东西（已刻意排除）：
    - 完整 156 道题数据集（470 KB，可一条命令重建）
    - 模型权重
    - 任何运行产物
